# Scoreboard Changer — Fabric 1.21.4

Мод для визуальной замены значений scoreboard на серверах Minecraft.

## Что умеет

- Визуально заменяет строки scoreboard (не создаёт свой — лишь перехватывает рендер)
- Кастомное меню настроек, открывается по биндингу
- Заменяет: **никнейм**, **ранг** (с выбором цвета), **монеты**, **токены**, **черепки**, **убийства**, **смерти**, **наиграно**
- Номер анархии берётся из настоящего scoreboard сервера автоматически
- **Свои цвета ранга**: добавляй цвет по коду, называй как хочешь, выбирай и удаляй (см. ниже)
- Все настройки сохраняются в `config/scoreboardchanger.json`

## Установка

1. Установи [Fabric Loader](https://fabricmc.net/use/installer/) для 1.21.4
2. Установи [Fabric API](https://modrinth.com/mod/fabric-api)
3. Скинь `.jar` мода в папку `mods/`


## Фейковый Т-Шоп

Работает только визуально и только если мод включён в меню.

- Открывается командой `.tshop` (или `/tshop`; название меняется в конфиге: `shopCommand`). Команда на сервер не уходит.
- Клик по предмету = покупка: токены в скорборде уменьшаются, предмет появляется в инвентаре (только у тебя, сервер его заберёт при обновлении инвентаря), в чат приходит сообщение о покупке.
- Товары: меню мода → **Т-Шоп...** (название с цветом, цена, предмет, описание через `|`). По умолчанию есть «Талисман Фантома».
- Тексты сообщений — в `config/scoreboardchanger.json`: `shopBuyMessage`, `shopNoMoneyMessage` (плейсхолдеры `{item}` `{price}` `{tokens}` `{anarchy}`).

## Анархия

Номер анархии берётся из настоящего скорборда сервера (строка вида `Анархия-505`), вручную вводить не нужно. Поле «Анархия (запас.)» используется, только если автоопределение выключено или скорборд не найден.

## Подмена чата

Меню мода → **Чат...** или команды (на сервер не уходят):

- `.fc learn` — запомнить формат: напиши в чат любое короткое слово, мод поймает настоящее сообщение и скопирует скобки, тег, цвета. Ник и ранг в нём заменяются на фейковые.
- `.fc текст` — одно фейковое сообщение.
- `.fc on` / `.fc off` — все твои сообщения остаются только у тебя в чате.
- `.fc reset` — забыть запомненный формат (будет работать запасной шаблон `{rank} {name} {msg}`).

## Сохранение меню сервера

Открой любое меню (Т-Шоп, талисманы, сферы...) и нажми **F8**. Содержимое (названия с цветами, лор, цены, id предметов) допишется в `config/scoreboardchanger_menus.txt`. Пройди все меню по цепочке, нажимая F8 в каждом, и отправь файл.

## Бинд

Зайди в **Настройки → Управление** и найди `Scoreboard Changer: Открыть меню`. Поставь любую клавишу.

## Свои цвета ранга

В меню мода (по биндингу) рядом с «Свои цвета:» нажми **Настроить...**:

1. Впиши название (например, `Сакура`).
2. Вставь код цвета. Понимаются форматы: `§x§f§f§c§5§0§0`, `xffc500`, `&#ffc500`, `#ffc500`,
   `<#ffc500>`, `<gradient:#FFE259:#FFA751>`. Несколько цветов в коде = градиент по буквам ранга.
   Поле ввода Minecraft вырезает символ `§` при вставке — это нормально, `xffc500` распознаётся так же.
3. **Добавить цвет** (или Enter). Цвет с тем же названием заменяется.
4. **Выбрать** делает цвет цветом ранга сразу, **Удалить** убирает его из списка.

Свои цвета появляются в кнопке «Цвет ранга» в основном меню после встроенных. Всё хранится
в `config/scoreboardchanger.json` (поле `customColors`) и сохраняется между запусками.

## Сборка через GitHub

1. Форкни / запушь проект на GitHub
2. GitHub Actions автоматически соберёт `.jar` при каждом пуше
3. Скачай артефакт в разделе **Actions → последний билд → Artifacts**

## Локальная сборка

```bash
./gradlew build
```

Готовый `.jar` будет в `build/libs/scoreboardchanger-1.0.0.jar`.

## Структура проекта

```
src/
  main/java/com/scoreboardchanger/
    config/ModConfig.java          — хранение и сохранение настроек (в т.ч. свои цвета)
    util/ColorParser.java          — разбор кода цвета из любого формата
    util/RankColors.java           — окраска текста цветом/градиентом
    mixin/
      ScoreboardObjectiveRendererMixin.java  — перехват рендера строк scoreboard
      PlayerListHudMixin.java                — заглушка для будущих фич
  client/java/com/scoreboardchanger/
    ScoreboardChangerClient.java   — точка входа, регистрация биндинга
    gui/ScoreboardChangerScreen.java — экран настроек
    gui/CustomColorsScreen.java      — экран своих цветов
```

## Важно

Мод работает **только визуально** на клиенте. Сервер ничего не видит.
Строки определяются по ключевым словам (`Ранг:`, `Монет:`, `Убийств:` и т.д.) — если на твоём сервере названия другие, поправь `ScoreboardObjectiveRendererMixin.java`.
